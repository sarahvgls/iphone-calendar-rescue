# Fonts

These are served from this folder rather than from Google Fonts, so the page
makes **no request to any third party at runtime**. Loading fonts from Google
would send every visitor's IP address to Google — which undermines the page's
own promise, needs a legal basis under GDPR, and in Germany has produced a
steady stream of Abmahnungen since the Landgericht München ruling of January
2022.

If you host this page yourself, keep them local.
